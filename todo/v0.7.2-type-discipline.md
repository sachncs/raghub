# v0.7.2 — Type discipline, `Any` reduction, dataclasses

## Theme

Reduce `Any` usage outside the `metadata` slot to zero; unify the
plugin registry; enforce dataclass discipline. This release locks the
type story for every later release.

## Breaking changes (R4 — no shims, no aliases, no deprecation)

- `PluginRegistry` API collapses from 11 parallel `register_X` /
  `get_X` pairs to a single `register(kind, name, obj)` / `get(kind,
  name)` pair with a `PluginKind` enum.
- `Job` (`raghub/ingest.py`) converted to `@dataclass(frozen=True,
  slots=True)`.
- Any code that imported `PluginRegistry.register_converter` (etc.)
  must migrate to the new shape.
- Any code that instantiated `Job(...)` as a plain class must
  migrate to the dataclass shape.

## Prerequisites

- `v0.7.1` is the current published release.

## Security review

This release is mostly internal; the security artefact is
`docs/security/threat-models/v0.7.2-type-discipline.md`.

### Threat model

| Threat | Mitigation |
|---|---|
| `Any`-typed plugin boundaries allow untyped objects to be registered; a malicious plugin could install itself where consumers expect a typed protocol. | Typed plugin boundaries (Protocol, Generic, concrete). CI grep enforces. |
| A frozen `Job` cannot be mutated post-construction, preventing a class of race-condition attacks where a worker mutates a job's payload between `claim` and `ack`. | Frozen dataclass + `slots=True`. |
| `Job` previously had no validation of its fields; an attacker could submit a job with `payload` containing a binary payload that looked like a document chunk but was actually an SQL fragment. | Add field validators in the new dataclass (covered by tests in v0.7.4 when the queue lands). |
| Untyped `Any` in telemetry could leak raw kwargs to a downstream sink (e.g. Langfuse), exposing secrets. | Typed Protocols prevent arbitrary attribute access. |

### Mitigations accepted

- Typed plugin registry.
- Frozen dataclass for `Job`.
- CI grep on `Any`.

### Out-of-scope

- Tenant identification spoofing: v0.7.3.
- Cross-tenant isolation: v0.7.6.
- Backup tampering: v0.7.8.
