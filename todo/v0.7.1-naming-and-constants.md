# v0.7.1 — Naming, forbidden names, constants, schema SoT

## Theme

Strip every forbidden identifier per `AGENTS.md`; promote magic
numbers to named constants; collapse duplicated schemas and SQL
fragments to a single source of truth. This release locks the
naming and shape of every later release.

## Breaking changes (R4 — no shims, no aliases, no deprecation)

- `raghub/utils.py` deleted; replaced by `raghub/io.py`,
  `raghub/retry.py`, `raghub/timing.py`, `raghub/await_sync.py`.
- `SlidingWindowManager` renamed to `SlidingWindowTrimmer`.
- `ConversationManager` renamed to `Conversations` (was an alias; the
  class name is now canonical).
- `capture_last_usage` renamed to `record_token_usage`.
- `Hasher` renamed to `FeatureHashingEmbedder`.
- `RAGHubGenie` renamed to `ChonkieGenieAdapter`.
- Every `_`-prefix identifier across 11 files renamed to public
  names or `__dunder__`.
- Documents schema (3 copies) collapsed to one module.
- Session INSERT (4 copies) collapsed to one helper.
- Default `3600` session-timeout constant promoted; the three literal
  sites updated.
- RRF `60` constant promoted; the two literal sites updated.
- LLM API key env-var tuple (3 copies) collapsed to one.
- Embedding model name `minishlab/potion-base-8M` (3 copies)
  collapsed to one constant.
- The `[langfuse]` extra (kept as a no-op in v0.7.0) removed from
  `pyproject.toml`.

## Prerequisites

- `v0.7.0` is the current published release.

## Security review

This release consolidates schemas and constants; the security
artefact is `docs/security/threat-models/v0.7.1-schema-sot.md`.

### Threat model

| Threat | Mitigation |
|---|---|
| Documents schema drifted between `repos.py` and `stores/__init__.py`. A row inserted via one store could not be read back via the other, or could leak into the wrong tenant table due to a column mismatch. | Single source of truth in `raghub/store/schema.py`. CI grep asserts one definition site. |
| Session INSERT drift could leave session-history JSON unencrypted in one path and encrypted in another; the inconsistent path would be the attacker entry point. | One helper. CI grep asserts one INSERT site. |
| Magic-number sprawl made audit difficult: changing `3600` in one place but not another could extend session lifetime unintentionally. | Named constants with single-source enforcement. |
| Renamed symbols with backward-compat shims would have left a deprecated code path that could be exploited. | No shims (R4). Old names raise `ImportError` immediately. |

### Mitigations accepted

- Documents schema: one module, one INSERT pattern.
- Sessions INSERT: one helper.
- Constants: single-source enforcement via grep + named constants.

### Out-of-scope

- Tenant identification spoofing: v0.7.3.
- Cross-tenant isolation: v0.7.6.
- Backup tampering: v0.7.8.
